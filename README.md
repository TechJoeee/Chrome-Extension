# Chrome Extension

A simple Chrome extension I built while learning HTML, CSS, and JavaScript.

## About

This project was built as part of my JavaScript learning journey. It helped me practice working with the Chrome Extensions API and understand how HTML, CSS, and JavaScript can work together to create a browser extension.

## Features

* Simple and clean interface
* Saves and displays user input
* Interacts with the browser through JavaScript
* Uses Chrome extension functionality

## Technologies

* HTML
* CSS
* JavaScript
* Chrome Extensions API

## What I Learned

While building this project, I practiced:

* JavaScript DOM manipulation
* Event listeners
* Working with browser APIs
* Handling user input
* Structuring a small web project
* Building and testing a Chrome extension

## How to Run

1. Clone or download this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Choose the project folder.
6. The extension will appear in your Chrome extensions.
